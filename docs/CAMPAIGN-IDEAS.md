# 从每日日报到蹭热度活动建议（通用方法）

`intel news run` 每天给你一份行业日报（`out/<日期>-news-digest.md`）。日报本身是**原料**；
这一步把它变成**能执行的活动建议**。

> 本文件只讲方法，不含任何具体业务语境 —— 你自己的产品/市场/玩法由你在第 ① 步提供。

## 五步法

1. **聚类**：把当天的条目按两个维度分组 —— **主题**（监管 / 并购 / 赞助 / 平台 / 政策）和
   **市场**（哪几个国家/地区被反复提到）。同一天里被多家媒体重复的那件事，就是当天的真热点。
2. **找时间锚**：热点里凡是带**日期、赛季、听证、截止日**的，优先做 —— 有明确窗口的资金和注意力都更集中。
3. **分流**：把热点分成两类 —— **可蹭**（有内容抓手、合规上说得清）与 **风险项**（禁令、处罚、灰色地带）。
   风险项不是不能碰，而是要先过合规、并且**只做行业观察，不做承诺**。
4. **落到形式**：每条可蹭热点配一个具体产出 —— 直播场次 / 短视频切片 / 图文 / 竞猜或抽奖玩法，
   并写明平台、目标市场时区、时长。
5. **写 brief**：给到创作者的是**要素**不是逐字稿（保留真实感）：一句话主题 + 3 个要点 + 必须挂的合规提示。

## 可直接复制的 prompt（喂给你的 AI）

```
读 out/<日期>-news-digest.md（今天的行业日报），按以下要求产出活动建议：

1) 先聚类：按主题 + 按被反复提到的市场分组，标出「被 2 家以上媒体同时提到」的事件。
2) 挑出 5-6 条值得蹭的，每条给我：事实（标题 + 链接 + 日期）、为什么是现在（时间锚）、
   怎么蹭（内容形式 / 活动形式）、落在哪些市场、执行时最可能踩的合规问题。
3) 再给 3 个「这周就能开跑」的小活动：目标 / 形式 / 时长 / 需要挂的合规提示 / 看什么指标。
4) 单独一段「今天别碰的」：列出新闻里的监管雷区，说明为什么现在不能碰。
5) 硬要求：每条必须带来源链接与日期；没有依据的不要写；不要用你的记忆补充事实。
   所有将要对外发布的话术只用英文或目标市场语言。
```

## 硬规则（别省）

- **不许编**：建议里的每条事实都要能指回日报里的链接与日期；拿不到就说拿不到。
- **合规前置**：年龄门（18+）、理性游戏提示、付费合作披露、地区性广告限制 —— 进 brief 而不是事后补。
- **不承诺**：不承诺收益、不承诺提现时效、不承诺"一定能过审"。
- **对外语言**：面向使用者的外发文案只用目标市场语言（本仓库约定：EN / ES）。
- **热点是快照**：行业热点 24 小时就换 —— 建议要当天生成、当天用，隔天失效。
- **风险项留着**：把它们写进内部 brief 的"不许说"清单，比事后撤稿便宜得多。
